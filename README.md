# Wuzard's Recipe Website

A **very simple** HTML recipe website created as a learning project from the Odin Project.

## Project Overview
This website features a collection of recipies connected from the main page. Each recipe is presented with a consisten structure including descriptions paragraphs, ingredient unordered lists, preparation instruction ordered lists, as well as images and links

## Features
- Clean, boilerplate HTML structure
- Consistent recipe layout across pages
- Ingredient lists
- Step-by-step preparation instructions
